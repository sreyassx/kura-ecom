## About

Kura is a modern e-commerce platform designed for a seamless shopping experience.

The project focuses on:

- Mobile-first UI
- Fast page loading
- Secure authentication
- Product management
- Cart & Checkout
- Order tracking
- Responsive design

---

## Features

- User Authentication
- Product Catalog
- Category Filtering
- Shopping Cart
- Checkout Flow
